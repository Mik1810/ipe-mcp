# Core M6: native validation, rendering, and export

M6 adds a local-only `NativeIpeAdapter` around the verified Ipe 7.2.30 command-line tools. It operates exclusively on serialized copies in mode-0700 temporary directories and returns bytes plus deterministic metadata; it never writes a session working file, source, revision, or snapshot. Each subprocess uses a fixed executable and argument vector with `shell: false`, a minimal environment, a bounded runtime and captured output, process-group termination, bounded artifact reads, and unconditional workspace cleanup.

Capability detection reports exactly `structural-only`, `full-7.2.30`, or `nightly`. On Linux, a verified native lane requires every configured tool to resolve to an ELF executable with independently verified Debian package ownership and version: all three Ipe programs must come from one identical `ipe` package, its upstream version must exactly match the Ipelib helper runtime, and `pdflatex` must come from TeX Live. The fixed artifact validators are also attested: `/usr/bin/pdfinfo` and `/usr/bin/pdftoppm` must belong to `poppler-utils`, and `/usr/bin/mutool` to `mupdf-tools`; their paths and owning packages appear in capability results. Exact 7.2.30 is `full-7.2.30`; coherently attested 7.3.x is `nightly`. Wrappers, copied/unowned binaries, mixed or unknown versions, runtime/converter mismatches, and missing validator provenance degrade with diagnostics. XML remains `70218`. The versioned `ipescript` bridge performs Ipelib load/save/reload, `Document:checkStyle()`, and `Document:runLatex()`.

The LaTeX profile permits an empty preamble or `\usepackage` declarations limited to `amsmath`, `amssymb`, `mathtools`, and `xcolor`. Every public document operation applies that policy before creating a workspace or starting a process. The configured `pdflatex` directory is first in the same minimal `PATH` for Ipelib, converters, and renderers, while direct TeX probes execute that exact absolute binary. It also sets `TMPDIR`/`TEXMFOUTPUT` to the confined workspace, uses paranoid TeX input/output policy, and disables shell escape. This is defense in depth for the initial local MVP, not a public hostile multi-tenant sandbox.

PDF export verifies a bounded envelope, obtains the physical page count with the fixed `pdfinfo`, and requires it to equal the deterministic page/view map. Every physical PDF page is rasterized by `pdftoppm` at 72 dpi and compared with the corresponding direct `iperender -nocrop` view. Comparison is symmetric: any added or omitted foreground component, including a one-pixel component, fails unless that component reaches corresponding foreground within the explicit two-pixel cross-renderer antialias neighborhood; overlapping foreground also has bounded channel-delta tolerance. The PDF is then round-tripped through the configured `ipetoipe -xml` and checked for recovered structure and semantics.

PNG and SVG are rendered with `-nocrop` separately for every page/view, so each artifact is pinned to the document paper box rather than the current content bounds. Metadata includes stable page/view IDs and indices, media type, byte count, SHA-256, and dimensions. PNG signature, legal color-type/bit-depth pairing, compression, filter, non-interlaced encoding, dimensions, pixels, and decoded bytes are checked before decode. The emitted PNG itself is decoded/rasterized by confined `mutool`. SVG source has a separate 4 MiB parser ceiling, rejects every XML processing instruction (including local or remote `xml-stylesheet`) before `mutool`, and requires finite dimensions and an exact four-number `viewBox`, valid local references, bounded XML structure, and painted nonzero geometry. The M6 conformance manifest pins dimensions and content hashes for every fixture view in both formats, and the gate changes the layout as a negative control.

Each public operation also has configurable limits for page/view states, document objects, expanded XML nodes, nesting depth, serialized source bytes, total retained artifact bytes, controlled native jobs (`maxSubprocesses`), and one wall-clock deadline. One centralized accounting contract preflights the exact controlled-job worst cases: capability detection uses `24` jobs, standalone PDF export uses `5 + 3S`, rendering uses `4S`, and full validation uses `34 + 7S`, where `S` is the number of page/view states. Document shape and strings are bounded with deadline checks before serialization; shared subtrees are charged for every serialized occurrence, and nesting is capped at 256 levels by default. The serialized byte count is checked again before a workspace is created, and inherited file-size limits bound producer files and cleanup work. Artifact sizes are charged before allocation. Each produced artifact is copied exactly once from a validated descriptor into a mode-0400 private snapshot; that same snapshot feeds every validator, converter, comparison, and returned byte buffer, eliminating inspection/reopen pathname races.

On Linux every controlled job uses fixed-argv `/usr/bin/bwrap` with a read-only host root, only its workspace writable, a new user and PID namespace, `--die-with-parent`, and a new session. The adapter attests the ELF at that fixed path against the installed Debian `bubblewrap` 0.11.1 package files/status before use. Per-job address-space, file-size, descendant-task, captured-output, and remaining-time limits are inherited inside that private namespace, so `maxProcesses` is local to the job and no host-wide `/usr/bin/ps` baseline or extra accounting launch exists. PID-namespace teardown contains ordinary process groups and `setsid` descendants after success, failure, or timeout.

Native reload compares metadata, preamble, stylesheet, bitmap asset, root extension, page/layer/view state, typed attribute maps, effect references, retained view XML, both accepted view-transform representations, and path/text/image/group/use object semantics. Only native identity fields that Ipe genuinely drops are reported as sidecar diagnostics; semantic loss is rejected. Errors are classified as unavailable, timeout, crash, output/resource limit, load, style, TeX, render, or export failures. Run `bash scripts/gates/check-m6.sh`; it includes every earlier gate, focused hostile subprocess/session tests, full native validation, negative style/TeX fixtures, exact mapping, pinned PNG/SVG goldens, a layout-change negative control, reproducibility, and cleanup checks.
