# ipe-mcp 1.0.0-rc.1

`ipe-mcp@1.0.0-rc.1` is the first thin npm release candidate for the local
stdio MCP server. It keeps the model-facing contract at `ipe-mcp/1`, the Ipe
XML format at `70218`, and the verified native runtime at Ipe `7.2.30`.

This candidate is **not published** until the protected release workflow is
run from the exact annotated `v1.0.0-rc.1` tag with explicit owner approval.
The default workflow mode only verifies and retains a candidate artifact.

## What is included

- the compiled JavaScript stdio server and `ipe-mcp` executable;
- TypeScript declarations and public package metadata;
- MIT license and essential installation, support, and versioning guides;
- a deterministic CycloneDX npm dependency SBOM;
- the two MIT runtime helpers required by the native adapter.

The package does not include, download, or install Ipe, TeX, Poppler, MuPDF,
Lua, bubblewrap, or another native executable. It has no install lifecycle
script, telemetry, HTTP listener, automatic updater, or implicit host
configuration.

## Supported lane

The verified full lane remains Ubuntu 26.04 WSL2 with Ipe 7.2.30 and the native
packages documented in `docs/guides/package-installation.md`. Installation on
another platform may start in `structural-only` mode, but that is capability
detection rather than a support claim.

## Install after publication

The prerelease uses the npm `next` tag; `latest` is not changed:

```bash
npm install --global ipe-mcp@1.0.0-rc.1
ipe-mcp
```

After the MCP connection starts, query `ipe_orientation` and
`ipe_get_capabilities`. The supported lane reports product `1.0.0-rc.1`,
contract `ipe-mcp/1`, and capability mode `full-7.2.30`.

## Verification

The release workflow uses the same clean-tarball gate as the reviewed local
candidate: explicit package allowlist, secret/native-binary scan, deterministic
SBOM, lifecycle-disabled clean install, fail-closed native discovery, and the
provider-neutral create/edit/recovery/validate/render/export scenario over
stdio with zero listeners.

The retained release manifest records the source commit/tree, tarball size,
SHA-1, SHA-256, SHA-512/npm integrity, dependency-lock digest, SBOM digest, and
release-notes digest. npm provenance links the public artifact to the protected
GitHub-hosted build.

## Known limits

- full native support is limited to the documented Ubuntu 26.04 WSL2 lane;
- macOS, Windows, non-WSL Linux, HTTP, live-Ipe synchronization, continuous
  video, and Ipe 7.3.x are separate M10 workstreams;
- native tools remain separately installed system programs;
- this is a prerelease and may require a corrected `rc.N` before `1.0.0`.

## Update and rollback

There is no automatic update. Pin the exact version in host configuration.
To rollback, reinstall the retained local `0.1.0` source candidate or a later
known-good exact npm version, restart the MCP connection, and re-query
orientation/capabilities. Review sidecar compatibility before any future major
downgrade. Published versions are immutable: a defect is corrected with a new
version, never by replacing this tarball.
