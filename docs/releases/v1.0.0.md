# ipe-mcp 1.0.0

The first stable ipe-mcp release keeps the MCP contract at `ipe-mcp/1` and
Ipe documents at XML `70218`. The verified Ipe runtime is `7.2.30`.

- Create and edit Ipe drawings and slides over stdio, validate and preview
  individual views, and export PDF or PNG.
- Import supported SVG and PDF content into editable Ipe documents.
- Connect over authenticated local HTTP or opt into live editing with the
  Ipe Qt bridge on Ubuntu 26.04 WSL2. GUI writes require explicit consent.

The headless toolchain is also qualified on Ubuntu 26.04 amd64 on the
GitHub-hosted Linux VM. Windows and macOS have capability probes that report
`structural-only`. See the support policy for the verified platform scope
and native dependencies, which are installed separately.

```bash
npm install --global --ignore-scripts ipe-mcp@1.0.0
```

After connecting, call `ipe_get_capabilities` to check the active mode.
For rollback, reinstall the published prerelease explicitly with
`npm install --global --ignore-scripts ipe-mcp@1.0.0-rc.1`.

The release includes the npm tarball, the integrity manifest and the
CycloneDX SBOM. The npm artifact carries GitHub Actions provenance.
